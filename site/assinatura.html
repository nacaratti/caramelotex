Code signing policy

Política de assinatura de código: como o instalador é gerado, quem aprova cada versão e o que o programa faz com os seus dados.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

A assinatura vale para as versões publicadas depois da aprovação do projeto pela SignPath Foundation. Nas versões assinadas, o Windows mostra a SignPath Foundation como editora do instalador.

Como o instalador é gerado

O instalador é montado pelo GitHub Actions a partir do código público do repositório, incluindo os scripts de build. Nenhum arquivo é compilado ou assinado no computador de alguém da equipe. Cada versão só é assinada depois de aprovada manualmente, e o resultado é publicado nas releases do GitHub.

Equipe e funções

Autores (committers)
Davi Pontes Nacaratti, que pode alterar o código sem outra revisão.
Revisores
Davi Pontes Nacaratti, que revisa toda contribuição de quem não é autor antes de entrar no código.
Aprovadores
Davi Pontes Nacaratti, que aprova cada pedido de assinatura.

Todos os membros usam autenticação em duas etapas no GitHub e na SignPath.

Privacidade

Este programa não transfere nenhuma informação para outros sistemas em rede, a menos que o usuário peça especificamente. Os documentos ficam nas pastas escolhidas pelo usuário, o PDF é gerado no computador e o corretor ortográfico funciona sem internet.

A única conexão acontece quando o usuário pede para instalar ou buscar um pacote LaTeX: o gerenciador do TeX Live (tlmgr) baixa a lista e os pacotes de um espelho da CTAN. Nessa conexão, o espelho recebe apenas o pedido de download, como acontece em qualquer download pela internet.
